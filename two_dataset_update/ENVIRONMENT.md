# Environment

The completed experiments used Python 3.12.13 on Windows 11, NumPy 2.4.4,
pandas 3.0.2, SciPy 1.17.1, scikit-learn 1.8.0, statsmodels 0.14.6,
threadpoolctl 3.6.0, joblib 1.5.3, matplotlib 3.10.9, and MNE 1.12.1.
Gate model training used PyTorch 2.9.0+cu129, CUDA 12.9, and an NVIDIA
GeForce RTX 5060 Laptop GPU. Original execution identities are included.
The portable evidence check uses requirements_verification.txt and runs on CPU.
The historical training runner pins its original execution environment;
rerunning training on a new machine requires a separate execution identity.
